# Testing

Run the standard-library suite with `python -m unittest discover -v` from the repository root. Tests create temporary Git repositories with synthetic manifests, source files, dependencies, ignored unknown data, and protected sentinels. Cleanup is limited to those temporary roots.

The suite covers scanner classification, Git-tracked and untracked preservation, secrets and local data, ignored unknown files, real and mocked symlink/reparse handling, Windows junctions, hard-link guards, lockfile context, staged/unstaged and tampered/stale plans, production and noninteractive apply refusal, test-only fixture cleanup, interruption journaling, restoration preview, report secrecy and lookup, JSON output, and skill metadata. On 2026-11-16, Python 3.14.10 ran 52 tests: 46 passed and 6 skipped. Two symlink tests were skipped because Windows denied symlink privilege (WinError 1314); three junction tests were skipped because junction creation was denied, including when retried with elevated test execution; one external-sentinel hard-link test was skipped because Windows returned WinError 5. Those cases remain unverified on this host. Permission-denied and mount-boundary behavior are not fully claimed as verified.

CI is configured for Windows, Ubuntu, and macOS with Python 3.10–3.14, including a wheel/console smoke and a separate adversarial-fixture job. The workflow YAML was inspected locally; no GitHub Actions run is available because the repository has not been pushed and Actions has not run.
